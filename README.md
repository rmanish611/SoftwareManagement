# Software Management

A public marketing and sales website for the software products I build. Visitors browse a catalog of my products, open a product page (screenshots, feature list, pricing, live-demo link, download or GitHub link) and buy or request a licence; I manage the catalog, pricing, orders and customer enquiries from an admin panel. It is a product showcase plus storefront.

## Stack
- Frontend: Angular
- Backend: ASP.NET Core Web API
- Database: SQL Server LocalDB (Dev) / Azure SQL (Prod)
