# 04 Requirements - THE CONTRACT

Fixed columns, never added to, removed or reordered: `REQ ID · Module · Actor · User Story · Acceptance Criteria · Business Rules · Entities Touched · MoSCoW · Phase · Depends On · Verified By`. IDs are permanent: never reused, renumbered or deleted. A requirement that is dropped is marked `Withdrawn`, it does not disappear. After approval this file is immutable and every change goes through `04a-amendments.md` with an ADR written first.

## Module Register

| Code | Module | Scope |
|---|---|---|
| SITE | Site content and company profile | pages, sections, navigation, services, technology stack, team, testimonials, media library, SEO metadata, redirects, versions, announcements |
| CAT | Product catalogue | products, categories, features, screenshots, pricing plans, plan features, demo links, FAQs, public catalogue and product pages, search and filtering |
| API | Public API directory | API entries, versions, status and sunset dates, public developer page |
| PRJ | Projects, case studies and clients | portfolio, case studies with outcome metrics, client logos with permission, testimonials linkage |
| LEAD | Lead capture and pipeline | public forms, captcha, consent, submissions, lead inbox, stages, activities, reminders, duplicates and merge, source and UTM, SLA |
| CUST | Customers and organisations | organisations, contacts, GSTIN and address, conversion from lead, deduplication |
| SALE | Quotes, tenants and subscriptions | quotes and line items, tenants, subscription lifecycle, invoices, payments, renewals, proration |
| IAM | Identity and access | admin users, roles, permissions, sign-in, lockout, refresh tokens, password reset, deny-by-default |
| NOTIF | Notifications | templates, transactional outbox with retries, delivery log, alerts, digest, unsubscribe |
| RPT | Reporting and dashboards | funnel, SLA, pipeline, revenue and MRR, renewals, traffic, exports |
| ADM | Back-office, settings and audit | company settings, holidays, audit viewer, import and export, retention, health and status |
| INT | Integrations and automation | outbound webhooks, demo health checks, sitemap and robots, JSON-LD, analytics consent, scheduling embed |
